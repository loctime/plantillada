**"Siempre que comenzamos un nuevo chat, leer el README consolidado (README.md) para tener el contexto completo del proyecto"**

### Beneficios de esta Regla
- ✅ **Contexto completo** desde el inicio de cada conversación
- ✅ **Información actualizada** sobre el estado del proyecto

Esta regla se aplicará automáticamente al inicio de cada nuevo chat para:
1. Leer el README.md consolidado
2. Entender la arquitectura del sistema
3. Conocer las funcionalidades disponibles
4. Tener referencias a documentación específica
5. Proporcionar respuestas más informadas
